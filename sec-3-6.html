    Section 3.6 Change of Variables

    Objectives

    • Understand the change of variables techniques.
      🔗
      🔗
    🔗
    We begin this section by exploring how a change of the dependent variable can be used to reduce a second order linear differential equation to a form can be solved using methods developed earlier. We then examine how a change of the independent variable can be used to develop solution techniques applicable to a variety of differential equations.
    🔗

    Subsection 3.6.1 Change of the Dependent Variable

    Let \(u(x)\) be a function to be chosen later and let \(w(x)\) be a function such that \(y(x) = u(x) w(x)\) is a solution of
    \begin{equation} y''+ a_1(x) y' + a_0(x)y = f(x)\tag{3.6.1} \end{equation}
    on some interval \(I,\) where \(a_1, a_0, f\) are continuous. Upon differentiation, we get
    \begin{equation*} \begin{split} y' &= u'w+uw'\\ y''&=u''w+2u'w'+uw''. \end{split} \end{equation*}
    Substituting these into the differential equation, we get
    \begin{equation} (u''+a_1u'+a_0u)w + (2u'+a_1u)w'+ uw'' = f.\tag{3.6.2} \end{equation}
    Our goal is to find \(w\) by choosing \(u\) in a way that simplifies (3.6.2). A choice of \(u\) can be made so that it satisfies one of the following two conditions:
    🔗
    Condition A: \(u''+ a_1 u' + a_0u=0,\) i.e., \(u\) is a solution of
    \begin{equation} y''+ a_1(x) y' + a_0(x)y = 0.\tag{3.6.3} \end{equation}
    Condition B: \(2u'+a_1(x)u=0\) and \(a_1\) is differentiable.
    🔗
    Suppose first that \(u\) satisfies Condition A. Then (3.6.2) becomes
    \begin{equation} (2u'+a_1u)w'+ uw'' = f,\tag{3.6.4} \end{equation}
    which, being a linear equation in \(w',\) can be solved first for \(w'\) and then for \(w.\) Thus, we have obtained a particular solution \(y_p(x) = u(x) w(x)\) of (3.6.1).
    🔗
    To find the general solution of (3.6.1), we need one another solution \(v(x)\) (3.6.3), such that \(u(x)\) and \(v(x)\) are linearly independent. Let \(v(x) = u(x) z(x)\) for some function \(z(x)\) such that \(v\) satisfies (3.6.3). Running the same calculation as above with \(z\) in place of \(w,\) but with \(f=0,\) we get
    \begin{equation} (2u'+a_1u)z'+ uz'' = 0,\tag{3.6.5} \end{equation}
    which solves for a nonzero function \(z(x).\) Consequently, the general solution to (3.6.1) is given by
    \begin{equation*} \begin{split} y &= c_1u(x)+ c_2v(x) + u(x)w(x)\\ &=c_1u(x)+ c_2u(x) z(x) + u(x)w(x)\\ &= u(x) (c_1 + c_2 z(x) + w(x)), \end{split} \end{equation*}
    where \(c_1\) and \(c_2\) are arbitrary constants.
    🔗
    Let us work through an example to show how the above procedure works.
    🔗

    Example 3.6.1.

    Find the general solution of
    \begin{equation*} (x-1)y''-x y'+y =1 \end{equation*}
    using the fact that \(u(x) = e^x\) is a solution to the associate homogeneous equation.
    🔗
    Solution.
    First, we note that \(a_1(x) = -\frac{x}{x-1}\) and \(f(x) = \frac{1}{x-1}\text{.}\) We compute \(w\) and \(z\) satisfying (3.6.4) and (3.6.5), respectively. Using (3.6.4), we get
    \begin{equation*} \left(2e^x-\frac{x}{x-1} e^x\right)w' + e^x w'' = \frac{1}{x-1} \end{equation*}
    which gives
    \begin{equation*} w''+\left(1-\frac{1}{x-1}\right)w' = \frac{e^{-x}}{x-1}. \end{equation*}
    The integrating factor is
    \begin{equation*} \frac{e^x}{x-1}. \end{equation*}
    Then
    \begin{equation*} \left(\frac{e^x}{x-1} w'\right)'= \frac{1}{(x-1)^2}, \end{equation*}
    which yields
    \begin{equation*} \frac{e^x}{x-1} w' = -\frac{1}{x-1}+A, \end{equation*}
    so that
    \begin{equation*} w' = -e^{-x} +A (x-1)e^{-x}. \end{equation*}
    Integrating yields
    \begin{equation*} w = e^{-x} -Axe^{-x} + B, \end{equation*}
    where \(A\) and \(B\) are arbitrary constants. We simply take \(w(x) = e^{-x},\) so that \(y_p(x) = u(x)w(x) = e^x e^{-x} = 1.\) Moreover, it is clear that \(z(x)=-Axe^{-x} + B\) solves (3.6.5) for all \(A\) and \(B\text{.}\) Since we only need one nonzero function \(z(x),\) we can simply take \(z(x) = xe^{-x}.\) Therefore \(v(x) = e^x z(x) = x.\) Hence the general solution of the given nonhomogeneous equation is
    \begin{equation*} y = c_1e^x + c_2 x +1, \end{equation*}
    where \(c_1\) and \(c_2\) are arbitrary constants.
    🔗
    🔗
    🔗
    Suppose now that \(u\) satisfies Condition B. Then \(2u'+a_1(x)u=0\) and so
    \begin{equation*} u' = -\frac{a_1}{2}u\quad \text{ so that }\quad u(x) = e^{-\frac{1}{2}\int a_1(x) \,dx}. \end{equation*}
    Moreover,
    \begin{equation} 2u''= - a_1 u' - a'_1 u =\left(\frac{a_1^2}{2}-a'_1\right)u.\tag{3.6.6} \end{equation}
    Then
    \begin{equation*} \begin{split} u''+a_1 u'+a_0 u &=\left(\frac{a_1^2}{4}-\frac{1}{2}a'_1\right)u - \frac{a_1^2}{2}u +a_0u\\ &=\left(a_0-\frac{a_1^2}{4}-\frac{a'_1}{2}\right)u. \end{split} \end{equation*}
    Substituting these into (3.6.2) gives
    \begin{equation} w''+\left(a_0-\frac{a_1^2}{4}-\frac{a'_1}{2}\right)w = g(x),\tag{3.6.7} \end{equation}
    where \(g(x) = \frac{f(x)}{u(x)}.\)
    🔗
    The differential equation (3.6.7) is said to be the normal form of (3.6.1). The coefficient of \(w\) in (3.6.7) is called the invariant of (3.6.1) and is denoted by \(I_y(x).\) That is,
    \begin{equation*} I_y(x) = a_0(x)-\frac{a_1^2(x)}{4}-\frac{a'_1(x)}{2}. \end{equation*}
    We observe that (3.6.7) turns into a differential equation with constant coefficients if and only if \(I_y(x)\) is constant. Consequently, (3.6.7) can be readily solved in this case. When \(I_w(x)\) is a constant function,
    \begin{equation*} y = u(x) w(x)= w(x)\;e^{-\frac{1}{2}\int a_1(x)\, dx} \end{equation*}
    is the general solution of (3.6.1) if and only if \(w\) is the general solution of (3.6.7).
    🔗
    We discuss some examples below to show how the above procedure works.
    🔗

    Example 3.6.2.

    Find the general solution of the differential equation
    \begin{equation*} y''+4y'+4y = \sin x \end{equation*}
    by using its normal form.
    🔗
    Solution.
    Comparing the differential equation with (3.6.1), we have \(a_0= a_1=4.\) So the invariant of the differential equation is
    \begin{equation*} I_y(x) = 4-\frac{4^2}{4}-0 = 0. \end{equation*}
    With the change of variable \(y = u(x) w(x)\) with \(u(x) = e^{-\frac{1}{2}\int 4\,dx} = e^{-2x},\) the normal form of the equation is
    \begin{equation*} w''(x) = \frac{\sin x}{u(x)}= e^{2x}\sin x. \end{equation*}
    Upon integration, we get
    \begin{equation*} w(x) = c_1+c_2 x-\frac{1}{25} e^{2 x} (4 \cos x-3 \sin x). \end{equation*}
    Therefore the general solution is
    \begin{equation*} y = e^{-2x}w(x) = c_1e^{-2x}+c_2 x e^{-2x}-\frac{1}{25} (4 \cos x-3 \sin x), \end{equation*}
    which is the same result we would have obtained by the method of undermined coefficients.
    🔗
    🔗
    🔗
    The above procedure is particularly helpful for solving linear equations with variable coefficients, as the following examples illustrate.
    🔗

    Example 3.6.3.

    Find the general solution of
    \begin{equation*} x^2y'' -2xy' + (k^2x^2+2)y = x^3\sin x, \end{equation*}
    where \(k\ne 1\) is a positive constant, by using its normal form.
    🔗
    Solution.
    Comparing the given equation with (3.6.1), we have
    \begin{equation*} a_0(x) = k^2+\frac{2}{x^2} \quad \text{ and } a_1(x) = - \frac{2}{x}. \end{equation*}
    So the invariant of the differential equation is
    \begin{equation*} I_y(x) = a_0(x)-\frac{a_1^2(x)}{4}-\frac{a'_1(x)}{2} =k^2+\frac{2}{x^2}-\frac{1}{x^2}- \frac{1}{x^2} = k^2. \end{equation*}
    Since
    \begin{equation*} u(x) = e^{-\frac{1}{2}\int \left(-\frac{2}{x}\right)\, dx} = e^{\ln\lvert x\rvert} = \lvert x\rvert, \end{equation*}
    we take \(u(x) = x.\) With the change of variable \(y = u(x) w(x),\) the differential equation is transformed into its normal form
    \begin{equation*} w'' + k^2 w = \frac{x\sin x}{x} = \sin x, \end{equation*}
    whose general solution, by the method of undetermined coefficients or variation of parameters, is
    \begin{equation*} w=c_1 \cos (k x)+c_2 \sin (k x)+\frac{\sin x}{k^2-1}, \end{equation*}
    where \(c_1\) and \(c_2\) are arbitrary constants. Hence the general solution of the given differential equation is
    \begin{equation*} y = x w(x) = c_1 x \cos (k x)+c_2 x \sin (k x)+\frac{x\sin x}{k^2-1}, \end{equation*}
    where \(c_1\) and \(c_2\) are arbitrary constants.
    🔗
    🔗
    🔗
    🔗

    Subsection 3.6.2 Change of the Independent Variable

    By changing the independent variable in the equation
    \begin{equation} y''+ a_1(x) y' + a_0(x)y = f(x)\tag{3.6.8} \end{equation}
    from \(x\) to \(t\) via a one-to-one function \(t= h(x)\) which is differentiable with the differentiable inverse \(x= h^{-1}(t),\) we may be able to transform (3.6.8) into a differential equation which may be solved using the methods that are previously discussed. To see how such a change of the independent variable works, we note
    \begin{equation*} \frac{dt}{dx} = h'(x) \end{equation*}
    and compute, by the chain rule, the derivatives
    \begin{equation} \frac{dy}{dx} = \frac{dy}{dt}\frac{dt}{dx} = \frac{dy}{dt}h'(x)\tag{3.6.9} \end{equation}
    and
    \begin{equation} \frac{d^2y}{dx^2} = \frac{d}{dt}\left(\frac{dy}{dt}h'(x)\right)\frac{dt}{dx} =\frac{d^2y}{dt^2} \left(h'(x)\right)^2+ h''(x) \frac{dy}{dt}.\tag{3.6.10} \end{equation}
    Substituting these into (3.6.8) gives
    \begin{equation} \frac{d^2y}{dt^2} \left(h'(x)\right)^2+ \left(h''(x) +a_1(x) h'(x)\right)\frac{dy}{dt}+ a_0(x)y= f(x),\tag{3.6.11} \end{equation}
    where \(x = h^{-1}(t).\) The substitution \(t = h(x)\) is beneficial only if it transforms (3.6.11) into an equation solvable by a known method.
    🔗
    To illustrate the effectiveness of changing the independent variable, we present two examples. The first involves a second order Cauchy-Euler equation, and the second is the Legendre equation of order \(n.\) Here, the term order refers to something different from the order of the differential equation itself. This distinction in the use of the same terminology is important to keep in mind.
    🔗

    Example 3.6.4.

    Find the general solution of the Cauchy-Euler equation
    \begin{equation} x^2 y''+3xy'+y = x\tag{3.6.12} \end{equation}
    by solving the transformed equation that is obtained from the change of variable \(t= \ln x.\)
    🔗
    Solution.
    Using \(t = h(x) = \ln x\) in (3.6.9) and (3.6.10), we find
    \begin{equation*} \frac{dy}{dx} = \frac{dy}{dt}h'(x) =\frac{1}{x}\frac{dy}{dt} \end{equation*}
    and
    \begin{equation*} \frac{d^2y}{dx^2} =\frac{d^2y}{dt^2} \left(h'(x)\right)^2+ h''(x) \frac{dy}{dt} = \frac{1}{x^2} \left(\frac{d^2y}{dt^2}-\frac{dy}{dt} \right). \end{equation*}
    Substituting these into (3.6.12) gives
    \begin{equation*} \frac{d^2y}{dt^2}+2\frac{dy}{dt}+ y= e^t. \end{equation*}
    The general solution of this equation is
    \begin{equation*} y= c_1 e^{-t} + c_2 t e^{-t} + \frac{1}{4} e^t, \end{equation*}
    where \(c_1\) and \(c_2\) are arbitrary constants. Since \(t=\ln x,\) it follows that the general solution of (3.6.12) is
    \begin{equation*} y= \frac{c_1}{x} + \frac{c_2 e^x}{x} + \frac{x}{4}, \end{equation*}
    where \(c_1\) and \(c_2\) are arbitrary constants.
    🔗
    🔗
    🔗

    Example 3.6.5. Legendre Equation.

    Transform the Legendre equation
    \begin{equation} y''+ (\cot x) \;y' +n(n+1)y=0\tag{3.6.13} \end{equation}
    of order \(n\) (a real number) using the change of variable \(t = \cos x.\)
    🔗
    Solution.
    Using \(t = h(x) = \cos x\) in (3.6.9) and (3.6.10), we find
    \begin{equation*} \frac{dy}{dx} = \frac{dy}{dt}h'(x) =-\sin x\frac{dy}{dt} \end{equation*}
    and
    \begin{equation*} \frac{d^2y}{dx^2} =\left(h'(x)\right)^2\frac{d^2y}{dt^2} + h''(x) \frac{dy}{dt} = \sin^2x \frac{d^2y}{dt^2} -\cos x\frac{dy}{dt} . \end{equation*}
    Substituting these into (3.6.13) gives
    \begin{equation*} \sin^2 x\frac{d^2y}{dt^2}-\cos x\frac{dy}{dt} +\cot x (-\sin x)\frac{dy}{dt}+ n (n+1)y= 0, \end{equation*}
    which simplifies to
    \begin{equation*} \sin^2 x\frac{d^2y}{dt^2}-2\cos x\frac{dy}{dt} +n (n+1)y= 0. \end{equation*}
    Using \(t= \cos x\) gives the standard form of the Legendre equation
    \begin{equation} (1-t^2)\frac{d^2y}{dt^2}- 2t\frac{dy}{dt}+ n(n+1)y = 0.\tag{3.6.14} \end{equation}
    🔗
    🔗
    🔗

    Remark 3.6.6.

    1. Since the invariant
      \begin{equation*} I_y(t) =\frac{n(n+1)}{1-t^2} - \frac{1}{4}\left(\frac{-2t}{1-t^2}\right)^2 - \frac{1}{2}\left(\frac{-2t}{1-t^2}\right) =\frac{n(n+1)}{1-t^2}+\frac{1}{(1-t^2)^2} \end{equation*}
      of (3.6.12) is not a constant, the transformed equation in \(w\) by the change of dependent variable \(y(t) = u(t)w(t)\) with
      \begin{equation*} u(t) = e^{ -\frac{1}{2}\int \left(\frac{-2t}{1-t^2}\right)\, dt} \end{equation*}
      does not have constant coefficients. Likewise, the invariant \(I_y(x)\) of (3.6.13) for the change of variable \(y(x) = u(x) w(x)\) with
      \begin{equation*} u(x) = e^{ -\frac{1}{2}\int \cot x\, dx} \end{equation*}
      is
      \begin{equation*} I_y(x) =n(n+1) - \frac{1}{4}\cot^2x + \frac{1}{2}\csc x\cot x \end{equation*}
      which is not a constant, and therefore the transformed equation in \(w\) does not have constant coefficients. A standard approach for solving the Legendre equation is the method of power series solutions, which will be discussed in Section 4.1.
      🔗
      🔗
    2. The Legendre equation (3.6.13) lies in an important class known as Sturm-Liouville problems, which are parameter dependent problems of the form
      \begin{equation} \big( a_1(x)\, y'\big)'+ \big( \lambda\, w(x) - a_0(x) \big) y = 0,\tag{3.6.15} \end{equation}
      \(\lambda\) being a parameter (called an eigenvalue) and \(p, q, r\) known functions of \(x.\) In fact, (3.6.13) can be written as
      \begin{equation*} \big((1-x^2)y'\big)'+n(n+1)y=0, \end{equation*}
      which is of the form (3.6.15) with \(a_1(x)= 1-x^2,\) \(w(x) =1,\) \(a_0(x)= 0,\) and \(\lambda = n(n+1).\) A detailed discussion of Sturm-Liouville problems, however, lies beyond the scope of this book.
      🔗
      🔗
    🔗
    🔗
    We now discuss a useful change of dependent variable for the equation
    \begin{equation} y''+ a_1(x) y' + a_0(x)y = f(x)\tag{3.6.16} \end{equation}
    given by
    \begin{equation*} t = h(x) = \int\sqrt{a_0(x)}\, dx. \end{equation*}
    It is clear that
    \begin{equation*} h'(x) = \sqrt{a_0(x)} \quad \text{ and }\quad h''(x) = \frac{a'_0(x)}{2\sqrt{a_0(x)}}. \end{equation*}
    Using this change of variable in (3.6.11), we get
    \begin{equation*} a_0(x)\frac{d^2y}{dt^2}+\left(\frac{a'_0(x)+2 a_0(x) a_1(x)}{2\sqrt{a_0(x)}}\right)\frac{dy}{dt} + a_0(x) y=0, \end{equation*}
    where \(x= h^{-1}(t).\) The above equation can be rewritten as
    \begin{equation} \frac{d^2y}{dt^2}+\left(\frac{a'_0(x)+2 a_0(x) a_1(x)}{2{\big(a_0(x)\big)}^{3/2}}\right)\frac{dy}{dt} + y=0.\tag{3.6.17} \end{equation}
    The equation (3.6.17) can be readily solved when
    \begin{equation*} \frac{a'_0(x)+2 a_0(x) a_1(x)}{2\big(a_0(x)\big)^{3/2}} =\text{ a constant}. \end{equation*}
    The arguments made above make sense only for those \(a_0(x)\) in (3.6.16) for which these considerations are meaningful.
    🔗
